# 🌡️ Temperature Converter - SkillCraft Technology (Task 01)

A modern, user-driven desktop application built with Python and native Tkinter. This program seamlessly converts temperature values between **Celsius (°C)**, **Fahrenheit (°F)**, and **Kelvin (K)** with a clean, high-end dark mode UI.

---

## ✨ Features
* **Multi-Scale Conversion:** Instantly computes equivalent temperatures across Celsius, Fahrenheit, and Kelvin from any source scale.
* **Modern Custom UI:** Styled with a dark-slate theme, elevated container cards, and high-contrast color accents built natively with Python Tkinter (no external dependencies required).
* **Robust Error Handling:** Features built-in validation to alert users if empty inputs or invalid characters are entered.
* **Fully Resizable:** Window layout supports smooth scaling and maximization.

---

## 🛠️ Tech Stack
* **Language:** Python 3.x
* **GUI Framework:** Tkinter (Standard Library)
